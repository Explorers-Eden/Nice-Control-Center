Going back to an older Minecraft version isn't supported by Minecraft itself; use Undo below instead.

     Area

     Pregenerate
    
					
    Generates every chunk in the area now, so players don't wait for terrain later and the map is complete. Runs while the server is up, only as fast as the server has room for (it slows down when ticks get long), and keeps going with nobody online.
    
					
    
					
    
						
						
						
					
    
				
    
				
    
					
     Trim outside the area
    
					
    Deletes all generated chunks outside the area (whole region files, single chunks along the edge, also entities and points of interest). They generate fresh when someone goes there. Only while the server is stopped; a backup is made first.

       Discord bridge
      
					
      Players link their Discord account to play, chat goes both ways (chat only, never commands), game events are posted, and the bot's status shows the server. 
      
					
      
						Setting up the bot (once)
						
        
							
      1. On discord.com/developers: New Application → Bot → Reset Token and copy the token.
        2. 
							
      2. On the same page, switch on Message Content Intent.
        3. 
							
      3. OAuth2 → URL Generator: scope bot; permissions View Channels, Send Messages, Read Message History, Manage Webhooks. Open the link and add the bot to your server.
        4. 
							
      4. In Discord: Settings → Advanced → Developer Mode. Right-click your server → Copy Server ID, right-click the chat channel → Copy Channel ID.
