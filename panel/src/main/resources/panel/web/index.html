 Log cleanup

					
Deletes old log files once a day after 05:00 (latest.log is never touched). Patterns work like in backups.

					

					

						
						
					

					

					

						
						
						
					

				

			


			

				

					
 Mod configs

					
Everything in config/. The format is checked before saving (JSON, JSON5, TOML, YAML, properties); simple files can also be edited as a form. Files open in their own editor window. Most mods read their config at start, so restart the server afterwards.

 Change version

					
An update swaps the server and mod files and starts the server. If it doesn't come up, the old files are put back (or, with a backup, the backup is restored). Going back to an older Minecraft version isn't supported by Minecraft itself; with a backup, Undo below brings everything back, the world included.

     Borders
    
					
    Per dimension, distances in blocks from the center. Inside the soft border is the permanent area: it's never trimmed. Between the soft and the hard border lie the outer wilds, which a scheduled task can reset (trim) every week. Nobody gets past the hard border: players are put back inside, and a square one also sets the world border so they see the wall. Hard border 0 = none.
    
					
    
						
    
							
    DimensionOnShapeCenter xCenter zSoft borderHard borderPregenWorld border
    
							
						
    
					
    
					
    
						
						
					
    
				
    
				
    
					
     Pregenerate
    
					
    Generates every chunk up to the hard border (or the soft border without one) in each dimension with Pregen ticked, one dimension after another, so players don't wait for terrain and the map is complete. It runs on its own thread in the mod, only as fast as the server has room for, keeps going with nobody online and carries on after a restart.
    
					
    
					
					
					
    
						
						
						
					
    
				
    
				
    
					
     Reset the outer wilds
    
					
    Deletes all generated chunks outside the soft border in every dimension with borders (whole region files, single chunks along the edge, also entities and points of interest). They generate fresh when someone goes there. Only while the server is stopped. To do this every week, add a task in Schedule with the Reset the outer wilds step (it stops and starts the server itself), or use the preset there.

       Discord bridge
      
					
      Players link their Discord account to play, chat goes both ways (chat only, never commands), game events are posted, and the bot's status shows the server. 
      
					
      
						Setting up the bot (once)
						
        
							
      1. On discord.com/developers: New Application → Bot → Reset Token and copy the token.
        2. 
							
      2. On the same page, switch on Message Content Intent.
        3. 
							
      3. OAuth2 → URL Generator: scope bot; permissions View Channels, Send Messages, Read Message History, Manage Webhooks. Open the link and add the bot to your server.
        4. 
							
      4. In Discord: Settings → Advanced → Developer Mode. Right-click your server → Copy Server ID, right-click the chat channel → Copy Channel ID.
        5.
